# AI 应用求职讲义

> 面向目标：2027 年 3 月前形成 AI 应用/Agent 岗位可投递材料。
> 学习时间：每天 1-2 小时。
> 数据原则：公开项目只用合成数据、公开数据或自建脱敏样例，绝不使用公司保密数据。

## 一、这套讲义与旧讲义有什么区别

旧讲义按 Python 知识点顺序讲，适合补语法基础。
这套讲义按求职交付物组织，目标不是“看完”，而是每个月产出一个可运行、可评测、可写进简历的结果。

## 二、你的起点

你已经完成或确认掌握：

- 变量、条件、循环
- 函数和类
- `self`、`__init__`
- 继承和 `super()`
- 异常处理、自定义异常、退出码
- JSON 转换和 JSON 文件读写
- `Path`、文件读写
- 模块和虚拟环境基础

仍需学习和形成工程产出：

- 类型注解和 Pydantic
- pytest 自动化测试
- HTTP、FastAPI、httpx
- async/await 基础
- RAG、向量检索、工具调用
- Agent 评测、观测、Docker 部署
- 小模型 LoRA/QLoRA 实验

## 四、如何使用

1. 每次学习只打开当月讲义和对应代码。
2. 先运行，再修改，再看报错。
3. 每完成一个功能就运行测试并提交 Git。
4. 不把公司数据、截图、文件名和真实参数放进本项目。
5. 看不懂时先定位具体代码行，不继续堆新知识。

## 五、数据保密约定

工作资料只能在公司内网使用。公开项目统一使用：

- Python 生成的合成质量数据
- 公开数据集
- 自己编写的模拟 SOP、FMEA 和 8D 文档

代码通过 `QualityDataSource` 之类的接口隔离数据源。公开仓库只保留合成实现，真实数据适配器不提交。
